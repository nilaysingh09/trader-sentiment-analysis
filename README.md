# trader-sentiment-analysis
# Trader Performance vs Market Sentiment

## Objective
Analyze the relationship between Bitcoin market sentiment and trader behavior/performance on Hyperliquid.

## Methodology
- Data cleaning
- Date alignment
- Feature engineering
- Behavioral analysis
- Trader segmentation

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Trader profitability varies significantly across sentiment regimes
- Greed periods show higher trading activity and better performance
- Fear periods increase volatility and risk-taking behavior
- Trader behavior adapts based on market conditions

- ## 🧠 Strategies Derived
- Reduce leverage during Fear periods
- Increase participation during Greed regimes
- Segment traders based on frequency for risk control
